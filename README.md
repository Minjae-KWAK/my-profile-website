# My Profile Website

Stitch 디자인을 바탕으로 제작한 반응형 개인 프로필 웹사이트입니다.
React나 Next.js 없이 HTML, CSS, JavaScript만 사용했습니다.

## 주요 기능

- 메뉴 클릭 시 해당 섹션으로 부드럽게 이동
- 프로젝트 카드 클릭 시 관련 링크 열기
- 이메일 및 문의 양식에서 메일 작성창 열기
- 데스크톱, 태블릿, 모바일 반응형 레이아웃
- 스크롤 위치에 따른 메뉴 활성화 및 콘텐츠 등장 효과

## 실행 방법

별도 설치나 빌드 과정 없이 `index.html`을 브라우저에서 열면 됩니다.

## 파일 구성

- `index.html`: 페이지 콘텐츠와 구조
- `styles.css`: 디자인 시스템과 반응형 스타일
- `script.js`: 내비게이션, 모바일 메뉴, 문의 양식 동작

> 이름, 연락처, 경력 및 프로젝트 정보는 예시 콘텐츠입니다.
